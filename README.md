# shinkansen_kitsuenjyo_smart_transit
新幹線乗車前後の喫煙を最も効率的に行える号車の検索および喫煙所位置案内をするアプリ

## 喫煙所号車ナビ（PWA）

東海道・山陽・九州・東北・北海道・秋田・山形・上越・北陸新幹線で、乗車駅・降車駅・列車・座席種別と「乗車前／降車後に吸うか」を選ぶと、ホームの喫煙所に最も近い号車をおすすめします。指定席予約のときに、そのまま使える予約メモをコピーできます。

- 番線が事前に分からない駅（東京・博多など）は、番線ごとの距離を平均して評価します
- 喫煙所が改札内コンコースにある駅や、場所が分かっていない駅は、号車による差がないものとして扱い、場所の説明だけを表示します
- 喫煙所ごとに信頼度（公式／要確認／情報不一致）と出典を表示します
- 列車ごとに運転区間を持ち、その区間を走らない列車は選べません
- はやぶさ＋こまち、やまびこ＋つばさのような併結列車は、行き先によって乗り通せる号車だけを候補にします
- 東京駅は東海道新幹線と東北・上越・北陸新幹線で改札もホームも別なので、別の駅（「東京」と「東京（東北・上越・北陸）」）として扱います

### 動かし方

依存パッケージはありません（Node.js 18以上）。

```bash
npm start
```

http://localhost:5173 を開きます。

```bash
npm test
```

### データについて

#### 路線系統（`routes`）と駅の並び（`lines`）

上り／下りは、系統（`routes`）ごとの駅の並び順で判定します。東海道〜九州は1本の系統、東京で分かれる路線は「東北・北海道」「東北・秋田」「東北・山形」「上越」「北陸」の系統に分け、東京〜盛岡などの共通区間の駅は複数の系統に含めています。駅選択と駅一覧のグループは `lines` で、各駅はちょうど1つのグループに属します。

#### 号車の向き

- 東海道・山陽・九州新幹線（16両・8両）: **1号車が下り方**（博多・鹿児島中央方）
- 東北・北海道・秋田・山形・上越・北陸新幹線（E5/H5・E2・E6・E8/E3・E7/W7系）: **1号車（こまち・つばさは11号車）が東京方**。E7/W7系も1号車が東京方、12号車（グランクラス）が敦賀・新潟方です（JR東日本の車両紹介ページ）
- はやぶさ＋こまちは東京方から1〜10号車（E5/H5系）、11〜17号車（E6系）の順につながり、やまびこ＋つばさも同じ並びです（仙台駅の編成案内・JR東日本の福島駅資料）

号車は編成全体で1から連番なので、号車の差をそのまま距離（1両25m）として計算します。デッキの向きは、秋田新幹線が大曲で進行方向を変えるため「東京寄り」ではなく「13号車寄り」のように隣の号車番号で表示します。

#### 列車（`trains`）

列車は `parts`（号車の範囲・系統・運転区間）の組で表します。併結列車は `parts` を2つ持ち、`coupled` に連結して走る区間を持ちます。区間を乗り通せる `parts` の号車だけが候補になります。

#### 喫煙所の号車（`cars`）

喫煙所の号車位置は、同じ駅でも編成の長さで変わります（例: 白石蔵王は17両編成なら8号車、10両編成なら6号車）。そのためホームの喫煙所は `cars` に **その駅に停まるときの両数ごと** の号車を持ちます。

```json
"cars": { "17": 8, "10": 6 }
```

- 併結列車は、連結して停まる駅では全体の両数（`"17"`）、切り離した後の駅では各部分の両数（はやぶさ `"10"`、こまち `"7"`）で引きます
- `null` は「喫煙所はあるが、その編成での号車は未確認」。出典に書かれていない編成は推測で換算せず、`null` にするかキーを持たせません
- 「8号車または9号車付近」のように号車の間にあるものは `8.5` と書き、「8〜9号車付近」と表示します
- 場所（ホームかコンコースか）も分からない喫煙所は `kind: "unknown"` として、号車計算には使いません

| 区間 | 状態 |

| 秋田新幹線 | 秋田は16号車付近（JREメディア・公式）。大曲は場所未確認、雫石・田沢湖・角館は公式一覧になく情報なし |

| 上越新幹線 | 高崎・越後湯沢・浦佐・燕三条・新潟などは第三者サイトによる **要確認**。熊谷は出典の号車（12両編成なのに14号車）が合わないため号車未確認。上毛高原・長岡は場所未確認 |

喫煙所の設置状況は変わりやすいため、各喫煙所に出典を付けています。データを直すときは、`sources` に出典を追加し、`verification` を実態に合わせて更新してください（`npm test` で整合性をチェックします）。

### 未対応・今後の課題

- 10両・12両編成での喫煙所位置の拡充（東京22・23番線、盛岡、宇都宮など）と、場所未確認の駅（山形新幹線・北陸新幹線の小松〜敦賀など）の調査
- 8両編成の喫煙所位置データの拡充（博多13〜16番線、新神戸・岡山・広島・小倉・熊本）。JR西日本の公式サイトでは山陽新幹線の全駅が喫煙ルーム設置駅とされているため、「情報なし」の駅の見直しも必要
- 6両編成（さくら・つばめ）、山陽新幹線の8両こだま・ひかりレールスター、E6系単独のやまびこ・なすの、ガーラ湯沢
- 列車ごとの停車駅（かがやきの通過駅など）は持っていないため、停車するかは時刻表で確認が必要
- コンコースにある喫煙所へ近い階段・エスカレーターから号車を割り出す機能
- 自由席の号車は列車や時期によって変わるため、予約画面でも確認が必要
- 実際に発着する番線（時刻表データ）との連携
