# shinkansen_kitsuenjyo_smart_transit
新幹線乗車前後の喫煙を最も効率的に行える号車の検索および喫煙所位置案内をするアプリ

## 喫煙所号車ナビ（PWA）

東海道・山陽・九州新幹線（のぞみ・ひかり・こだまの16両編成、みずほ・さくらの8両編成）で、乗車駅・降車駅・列車・座席種別と「乗車前／降車後に吸うか」を選ぶと、ホームの喫煙所に最も近い号車をおすすめします。指定席予約のときに、そのまま使える予約メモをコピーできます。

- 番線が事前に分からない駅（東京・博多など）は、番線ごとの距離を平均して評価します
- 喫煙所がコンコースにある駅は、号車による差がないものとして扱い、場所の説明だけを表示します
- 喫煙所ごとに信頼度（公式／要確認／情報不一致）と出典を表示します
- 列車ごとに運転区間を持ち、その区間を走らない列車は選べません

### 動かし方

依存パッケージはありません（Node.js 18以上）。

```bash
npm start
```

http://localhost:5173 を開きます。

```bash
npm test
```

### 構成

| パス | 内容 |
| --- | --- |
| `data/stations.json` | 駅・喫煙所・出典・列車（編成両数・運転区間・座席配置）データ |
| `src/recommend.js` | おすすめ号車の計算（DOM非依存・テスト対象） |
| `src/app.js` | 画面描画 |
| `sw.js`, `manifest.webmanifest` | PWA（HTTPS配信時のみ Service Worker を登録） |

### データについて

号車は16両・8両編成とも **1号車が下り方（博多・鹿児島中央方）** です。

喫煙所の号車位置は編成の長さで変わるため、ホームの喫煙所には `car`（16両編成での号車）と `car8`（8両編成での号車）を別々に持たせています。16両用ホームで8両編成がどこに停まるかは駅・番線ごとに違い、機械的に換算できないため、出典に書かれている場合だけ `car8` を登録し、それ以外は `null`（未確認）にしています。

| 区間 | 状態 |
| --- | --- |
| 東海道新幹線 | JR東海「各駅喫煙ルーム設置箇所のご案内（2026年1月30日時点）」の構内図から号車を読み取り、公式として登録。ホームに喫煙所があるのは東京・三島・静岡・浜松・名古屋で、他の12駅はコンコース |
| 山陽新幹線（16両） | JR西日本は号車単位の公式情報を公開していないため、第三者サイトをもとに **要確認** として登録。博多は情報源によって号車が異なり（**情報不一致**）、小倉と岡山の下りは号車が未確認、他の多くの駅は情報なし |
| 山陽・九州新幹線（8両） | 8両編成での位置が分かっているのは博多11・12番線（8号車付近）のみ。熊本はホームに喫煙ルームあり（JR九州公式）だが号車未確認、鹿児島中央は改札内 |

喫煙所の設置状況は変わりやすいため、各喫煙所に出典を付けています。データを直すときは、`sources` に出典を追加し、`verification` を実態に合わせて更新してください（`npm test` で整合性をチェックします）。

### 未対応・今後の課題

- 8両編成の喫煙所位置データの拡充（博多13〜16番線、新神戸・岡山・広島・小倉・熊本）
- 6両編成（さくら・つばめ）、山陽新幹線の8両こだま・ひかりレールスター、東北・上越・北陸など他の新幹線
- コンコースにある喫煙所へ近い階段・エスカレーターから号車を割り出す機能
- 自由席の号車は列車や時期によって変わるため、予約画面でも確認が必要
- 実際に発着する番線（時刻表データ）との連携
